# VAYU-SARTHI

Live prototype for Smart India Hackathon 2026, problem statement 26250 (Air Power: Dynamic Air Operations &
Resource Optimisation), team NexaBuild. It plans the air tasking day and re-plans it in seconds when something
changes, moving as few aircraft as possible. All scenario data is notional.

Source code: https://github.com/DeepakSinghhh/Air-power-Dynamic

Each browser tab gets its own session. The first plan takes about 10 seconds.
